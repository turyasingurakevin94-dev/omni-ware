# Sales · the app built to its approved canvas (28 Oct 2026)

Kevin approved the redrawn Sales canvas (75 boards, the "world-class" passes of
28 Oct) and said: build it, don't drift, and put anything left out on the canvas
first. This file is the record of that build.

## 1. How it is built

- **One component layer** (`sales.html`, "THE KIT"): the CSS and one JS function
  per canvas component (`K.hd`, `K.sh`, `K.th`, `K.row`, `K.chip`, `K.f`, `K.p`,
  `K.bp/bs/bt/bi`, `K.card`, `K.label`, `K.notice`, `K.seg`, `K.qty`, `K.tick`,
  `K.radio`, `K.tl`, `K.paper`, `K.dock`, `K.imp`, `K.skel`, `K.empty`), with the
  canvas's own icon set (`KI`). Every screen is rebuilt from these, so the same
  thing looks and behaves the same everywhere.
- **One deviation from the canvas, for contrast.** The canvas's caption grey
  #767F91 is 3.9:1 on the warm ground; the app keeps its #656E80 (4.7:1, pinned
  by `test/sales-app.test.js`). It looks the same and reads in sunlight.
- **The paper stamp** ("PAID") sits on the total row, not over a line's amount
  (canvas and app both moved).

## 8. Built differently from a gap board (to redraw)

- **GO4TellMore, a shut window:** the board says the message still goes as the shop's message; the build keeps today's behaviour (WhatsApp opens with it typed), because a picture cannot go as the shop's message. Say if the text alone should go.
- **O11, which fix:** the board draws the amount and the method; moving a payment to another bill or day (today's "The bill", "The day") is not on it, so it is gone from Sales. Say if it should stay.

- **GU6NewMore, "number already used":** the white button is "Change the number", not "Save anyway". The app has always refused a second customer with a number already saved (`phoneTwin`), and the build keeps that rule.
- **K2, the third “They gave” chip:** GK2 makes the third chip the amount typed in, so it reads “Other ✎” until something is typed, where K2 drew a second round note (60,000). The typed amount (SAL-20) is kept that way.
- **K6, the slide's words:** the app says “Back online to sell” (the glossary's word for a slide that waits for the connection), not the board's “Waiting for a connection”. The board is to be brought in line.
- **N4 and N9, the bin:** N4 draws an ✕ labelled Remove; N9 says “use the bin”. The app uses the bin, so both boards say the same thing.
- **GN4, sold whole:** under the sentence the app keeps one white button, “Make it 50 · the full carton”, so the full carton is one tap (it was there before).
- **GN3, the order picture:** “Send the order picture” in the ⋯ sends it now, as it stands. Placing the order still sends it when the chat is open (N12's “Picture sent to Kato”), unless that same picture already went.
- **N5, while adding:** the dock steps aside while something is typed, as the board draws it; adding an item brings it back.
- **K2, the last one:** at a count of 1 the minus becomes the bin, so a line comes off the counter without a second control.
- **GK4, before asking:** beside “Ask Ruth” the white button sells at the shop's price straight away; after asking it is K4's “Sell at 185,000 instead”.
