# Sales · the app built to its approved canvas (28 Oct 2026)

Kevin approved the redrawn Sales canvas (75 boards, the "world-class" passes of
28 Oct) and said: build it, don't drift, and put anything left out on the canvas
first. This file is the record of that build.

## 1. How it is built

- **One component layer** (`sales.html`, "THE KIT"): the CSS and one JS function
  per canvas component (`K.hd`, `K.sh`, `K.th`, `K.row`, `K.chip`, `K.f`, `K.p`,
  `K.bp/bs/bt/bi`, `K.card`, `K.label`, `K.notice`, `K.seg`, `K.qty`, `K.tick`,
  `K.radio`, `K.tl`, `K.paper`, `K.dock`, `K.imp`, `K.skel`, `K.empty`), with the
  canvas's own icon set (`KI`). Every screen is rebuilt from these, so the same
  thing looks and behaves the same everywhere.
- **One deviation from the canvas, for contrast.** The canvas's caption grey
  #767F91 is 3.9:1 on the warm ground; the app keeps its #656E80 (4.7:1, pinned
  by `test/sales-app.test.js`). It looks the same and reads in sunlight.
- **The paper stamp** ("PAID") sits on the total row, not over a line's amount
  (canvas and app both moved).

## 2. Decisions Kevin made (28 Oct), now in `docs/decision-rights.md`

| Question | Answer | Row |
|---|---|---|
| Who gives or moves a customer's chat | A salesperson takes a new number first-come and can hand their own customer to a teammate with a note; the Manager moves anyone | `chat.take` (Sales, Manager), `chat.move` (Manager) — Built: no, until 0169 |
| Replying in a teammate's customer's chat | Anyone may reply so no customer waits; each reply carries the sender's name and pushes the chat's salesperson | `msg.reply` |
| Customer kind (Contractor / Reseller / Retail) | Sales sets it when adding; after that only the Manager changes it | `customer.edit` |
| Build order | Build the parts with no open gap now, on the branch; nothing reaches main until every gap board is approved | — |

Migration **0169** is reserved for this build (Sales, seventh).

## 6. Server work (0169), once the boards are approved

- `wa_conversations.owner_user_id` / `owner_at`; `take_conversation`, `hand_conversation(conv, to, note)`, `move_conversation`; `wa_conv_events` (the log); update RLS tightened; pushes `chat.handed`, `chat.reply_by_other`.
- `wa_notes` (team notes) with member RLS and a push on @mention.
- `customers.kind`, its load mapping and insert; only the Manager changes it after.
- `order.cancel` (cancel an order before its invoice): the Manager decides, Sales asks (`invoice_asks.kind` 'cancel'), the Store puts back what was packed.
- `payment_asks`: one ask that corrects amount and method together.
- A stored, resolvable answer for a bill "being checked" (U4).
- An "other" ask kind with free text to the Manager (O8 "Something else").
- Team presence ("3 on now", "away") via a presence RPC; a per-sender message count for the year (C4).
- Not in this build: audio and document send in `wa-send` (C2's mic and clip stay hidden until it can).
