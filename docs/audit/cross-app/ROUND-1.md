## What the code does today (the cause of each)

| ID | Cause found |

| SAL-3 | `Outbox.run()` (`src/core/outbox.ts:95`) keeps **every** new write while any item is not `refused`, and `flush()` breaks at the first item that fails as "no signal" (`:116`). `flush()` is called only on the window's `online` event and Try again (`src/apps/sales/shell/store.ts:224`), never on open, focus or a timer. The head shows Live whatever the outbox holds (`src/ui/Hero.tsx:70`). "Not sent yet" appears only when offline (`today/Today.tsx:109,139`). So one write that keeps failing as "no signal" (the #0586 ask, 8 tries) holds every later write, and nothing says so. A missing order throws a plain `refused` (`supabase/index.ts:36`); the 8 "network" tries mean the error that reached the outbox was a fetch failure (`isOffline` matches any message with "fetch"/"network"), e.g. the books read inside `order()` failing first on a just-woken phone.
